# آرمه‌بنای پارس — قالب سایت شرکت مهندسی عمران

قالب تک‌صفحه‌ای فارسی (RTL) برای شرکت‌های مهندسی عمران و سازه، با HTML/CSS/JS خالص و بدون هیچ وابستگی یا فریم‌ورک.

## اجرا

فایل `index.html` را مستقیم در مرورگر باز کنید، یا یک سرور ساده بالا بیاورید:

```bash
python -m http.server 8777
```

سپس به `http://localhost:8777` بروید.

## ساختار

```
index.html      کل صفحه: مارک‌آپ، استایل و اسکریپت
assets/         تصاویر و آیکون‌ها
```

## امکانات

- **ریسپانسیو** در سه بریک‌پوینت (۱۱۰۰px و ۷۰۰px) با منوی همبرگری
- **تم روشن/تاریک** با کلید تغییر در هدر و ذخیره انتخاب در `localStorage`
- **انیمیشن**: ورود صفحه، ظاهر شدن پلکانی با اسکرول (IntersectionObserver)، شمارنده اعداد با ارقام فارسی، آکاردئون نرم و افکت‌های هاور
- رعایت `prefers-reduced-motion` برای کاربرانی که انیمیشن کمتر می‌خواهند
- انیمیشن‌های ورودی فقط پس از تأیید قابل‌نمایش بودن صفحه فعال می‌شوند تا محتوا هیچ‌وقت نامرئی نماند

## توجه درباره تصاویر

تصاویر پوشه `assets/` از دموی یک قالب تجاری وردپرس گرفته شده‌اند و صرفاً برای نمونه‌سازی (placeholder) هستند. **پیش از انتشار واقعی، آن‌ها را با تصاویر پروژه‌های خودتان یا تصاویر دارای مجوز جایگزین کنید.** محتوای متنی (نام شرکت، شماره تماس، پروژه‌ها و گواهینامه‌ها) نیز نمونه است و باید با اطلاعات واقعی عوض شود.
